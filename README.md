# Daily Project Tracker

A lightweight React + Vite task tracker built for daily project and work management.

## Features

- Create, edit, and delete tasks
- Set project, category, recurrence, and priority
- Track time spent using built-in task timers
- Filter tasks by Today, Upcoming, Completed, and Active
- View key work summary cards for planning and progress
- Export task data as JSON
- Persistent task data using localStorage

## Tech stack

- React
- Vite
- CSS

## Getting started

1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
3. Open the local URL shown in the terminal.

## Project structure

- `src/App.jsx` — main application logic and UI
- `src/styles.css` — styling for dashboard layout and components
- `src/main.jsx` — app entry point

## Notes

This starter version is designed as a useful MVP and is intentionally simple to extend.
